문서 편집

실제 RHWP Core가 문서를 조판하고 저장합니다.

텍스트 선택
Shift+방향키 · F3(본문: 2회 낱말 / 3회 문단 / 4회 전체) · 드래그
셀 블록
F5 → F5 또는 F3 → 방향키
셀 블록에서 F8: 줄 전체 선택
F5 세 번: 표 전체 셀
셀 이동
Tab / Shift+Tab
텍스트 커서 이동
Ctrl+←/→: 본문·셀 텍스트 단어 이동(현재 문단)
Ctrl+↑/↓: 같은 본문·셀 안 앞·다음 문단 시작
Alt+Home / Alt+End: 현재 문단 처음·끝
Alt+Home은 편집 초점에서만 처리하며 Chrome 홈 이동과 겹칩니다(실키 환경 별도 확인).
Alt+PageUp / Alt+PageDown: 앞·다음 쪽 처음
서식
Ctrl+B · Alt+L · Alt+T
