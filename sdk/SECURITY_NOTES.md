# 보안 경계

- 정확한 편집기 origin과 즉시 부모, 세션 MessagePort, 버전과 capability를 검증합니다. 출처 목록을 메시지로 바꾸거나 wildcard targetOrigin을 쓰지 않습니다.
- 작업본/instance/revision, 선택 원문·서식·범위, 승인 digest 및 operation ID를 고정합니다. 새 위치나 수정문을 apply 단계에 다시 넘기지 않습니다. 승인 proof는 신뢰된 Host가 사용자 검토 후 발급합니다.
- 파일 길이/해시/형식 및 네이티브 구조 검사를 통과하지 못한 입력을 일반 로더로 되돌리지 않습니다. 입력 지원은 지정된 온편집 범위에 한정됩니다.
- 샘플 Host의 메모리 proof와 권한은 실습용입니다. loopback에서만 실행하고 두 합성 파일만 승인합니다. 실제 서버 인증·권한·저장소·모델은 연결하는 Host의 책임입니다. 이 SDK는 해당 서비스를 제공하지 않습니다.
- 배포물에는 운영 설정·키·실사용 문서·편집기 자산이 없습니다. 테스트 출력과 승인 정보는 운영 로그나 공유 파일에 넣지 않습니다.
